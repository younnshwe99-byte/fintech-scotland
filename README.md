Investment readiness score

Investment readiness was operationalised using the Payne scorecard dimensions and weights set out in Table 1. For each firm, the text disclosed on its FinTech Scotland directory profile [https://www.fintechscotland.com/cluster/fintech-community/] comprising the company overview, company story and team biographies — was assessed against each of the six dimensions and awarded a score between 0 and 100, where 0 indicates no positive signal and 100 an exceptionally strong and specific signal. Dimension scores were then multiplied by their respective weights and summed to produce a composite score out of 100.
Assessment was carried out using a large language model, applied through a standardised rubric specifying, for each dimension, the disclosure types that warranted higher and lower scores. Every firm was assessed using an identical rubric and prompt structure, with only the firm-specific text varying between cases, ensuring consistent application of the criteria across the sample. Three decision rules were embedded in the rubric: absence of evidence was scored low or neutral rather than assumed positive; no credit was awarded for characteristics the text did not state; and unsupported promotional language did not raise a score. The model was additionally required to return a one-sentence justification for each dimension score, referencing the specific disclosure that drove it, allowing every score to be audited against the underlying text.
